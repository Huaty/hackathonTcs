How we score risk

Every action gets a score from 0–100 in four steps: know what's normal, check it against fixed rules, let AI add bounded context, then calculate a final number. No step can override the ones before it.

The four steps

1

Learn what's normal

We build a 30-day profile per person: usual hours, locations, and services. Needs at least 20 events across 7 days before we trust it.

2

Check fixed rules

The action is checked against a published rule catalog — admin changes, secret access, unusual times. Each match adds set points.

3

Add AI context

AI reviews the surrounding events and may nudge the score, only within a fixed range, and only when it can point to real evidence.

4

Calculate final score

Rule points plus the AI nudge, never below the minimum set by the most serious rule that matched. That number sets severity.

Why the AI step can be trusted

BoundedCan only move the score by one of six fixed amounts, never an arbitrary number.
Evidence requiredAny adjustment must cite real event IDs from that person's activity.
Confidence checkedBelow 60% confidence, the adjustment is discarded automatically.
Fails safeIf the AI is unavailable, scoring still runs on rules alone — nothing blocks.
